# Reference: the real UMS, structure only

Observed 2026-11-01 from a student's own logged-in session (read only, nothing submitted).
This file records **layout, flows and menu structure** for Univra to mirror. It holds no
personal data. Univra keeps its own name, logo and colours (see docs/plan.md, M2).

## Login

Centred page: crest + "UMS / University Management System" wordmark on top, white card below.
Fields in order: "Log in" heading with a campus dropdown beside it, User ID (person icon),
Password (show/hide eye), a landing-page dropdown (default "Dashboard"), a captcha, Login
button, "Forgot your password?", and a "Student Mail" link.

## Portal shell

- **Top strip:** one announcement at a time with « » arrows to step through them.
- **Header:** logo left. The five menus are right-aligned (Academics, Administrative,
  Important Links, Student Services, Quick Links), then a search icon, then the student
  block: name; "VID: … | Section: …"; programme; photo with a dropdown caret.
- **Left rail:** wide icon column with a label under each icon (Dashboard, the mobile app,
  live classes, My Class, a counselling service); collapsible with a « button.
- **Mega-menus:** each menu opens a panel of headed groups, each a list of links.
- **Quick Links** is personal: empty by default ("No quick link available. Go to search menu
  to add quick link."). Students pin entries from the menu search.

## Dashboard (top to bottom)

1. Password notice, small and right-aligned, always shown:
   "Pwd will expire after N days, do change your pwd on or before DD-MM-YYYY".
2. **Important Links:** heading plus a row of pill buttons (Hostel Booking, RMS, Fee
   Dashboard, Issued Books, Academic Calendar, Emergency Numbers, Certificate Request,
   Part-time job, …).
3. Row: **banner carousel** (wide) | **Happening** (news list) | **My Messages**.
4. Row: **My Courses** | **Fee** | **Pending Assignments** | **Events**.
5. **Placement Details:** "Recently Placed" (company, CTC, students placed) and
   "Today's Placement Drives".
6. **Important Announcements:** category tabs with counts (Academic, Administrative/Misc,
   Co-curricular/Sports/Cultural, Examination, Placement, Research); each notice has a title,
   reference number, date, body, attachments and "Uploaded By".

Card style: white card with a coloured border. The title is a pill "tab" with an icon,
sitting on the card's top edge. The footer has a small note on the left ("* Messages Sent by
Teachers") and a pill button on the right ("All Messages", "View More").

- **My Courses:** per course an attendance ring, "CODE : TITLE", Term, "Roll No : … /
  Group N", exam pattern, and links (IP, Syllabus, Timetable, Outcomes, View Books). Footer:
  "CGPA : x.x  ATTENDANCE : y%" (aggregate).
- **Fee:** "NIL" when nothing is due; links "Fee Notification", "Transactions".
- **Pending Assignments:** "CODE | Course : CODE | Kind | Last Date : DD-MM-YYYY";
  buttons "Upload", "View Assignments".
- **My Messages:** "Subject - By Sender (Mon DD, YYYY)" then the body.

**Login pop-up, "Campus Drive Notifications":** "You are eligible for below drives", a
numbered list ("01. ON CAMPUS Drive of X … Registration/De-registration open till DATE"),
"Check venue through UMS.", buttons **Mark as Read** and **Remind me later**.

## RMS: Relationship Management System

A standalone page **outside the portal shell**: its own header (logo left, centred title
"Relationship Management System (RMS)", "UMS Home" link right) and two icon tabs,
**Log Request** and **RMS History**.

- **Log Request:** step 1 is a list of five declarations, each with a check mark, and a
  single **Agree & Proceed** button. (The form after it wasn't opened: agreeing is recorded
  against the account.)
- **RMS History:** filter pills **Total / Open / Closed** with counts. One full-width card per
  request: status tag, SubCategory, Request ID (`dept/Mon-YY/NNNNN`), Dated, bold title,
  description in a tinted box, **Closing Remarks** in a second box, and icon buttons for
  **Feedback** and details.
- The older "View Request Status" page adds a fourth count, **Rating Pending for Closed
  Requests**, a status filter, and "No of Days" per request.

## Menu structure (groups → entries)

**Academics:** Cohorts (4) · Examination System (~32: results, certificates, date sheet,
re-appear/re-evaluation registration, backlog registration, faculty feedback, online
transactions, …) · Learning Management System (~36: assignment upload/download, view
attendance, view time table, instruction plans, syllabus, session calendar, event duty
leaves, …) · Library Management System (Discussion Room Booking, Dissertation/Thesis,
E-Resources, Library Search) · Ph.D. Induction · Placement Services (registration, portal,
OJT/internship application and attendance, …) · Polling (electives, specialisation, minors)
· Project/Dissertation (8) · Research and Development (14) · Skill Development Courses (3).

**Administrative:** Alumni Services (3) · Central Mail System (2) · Fee and Scholarship
System (Fee Dashboard, fee certificates, refund, outer-agency scholarship, bank loan
documents, confirmation of fee deposited, scholarship requests/letter/policies, fee payment
schedule, fee receipts, fee status) · My Profile (Virtual ID Card, Profile Update) ·
Residential Services (~21: hostel booking, hostel leave application, leave slip, guidelines,
mutual shifting, housekeeping rating, special food, …) · Security and Safety (case details,
RFID application, parent pass request, case statement).

**Important Links:** Capstone/Dissertation/Internship guidelines (5) · Change Password
(Change UMS Password, Reset Internet Password) · Miscellaneous Links (duplicate ID card,
appointment system, accommodation details, emergency contact numbers, view academic
calendar, campus map, medical staff list, lost and found, view my messages, …) · Policies,
Rules, Guidelines and Formats (13).

**Student Services:** Feedback and Surveys (13) · Health Services (Counseling Psychologist
Appointment, Doctor Appointment) · **Relationship Management System (RMS): Log Request,
View Request Status** · Student Welfare (~25: clubs, events, part-time job registration,
transport preference, uniform size selection, …).

**Quick Links:** the student's own pinned entries (see above).
