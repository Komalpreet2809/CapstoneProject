# Univra · VoiceServe demo

A demo university student portal (**Univra**) with **VoiceServe**, an assistant you can talk or
type to. Every student, course and request here is **synthetic**; this is not a real
university system.

**Open the app directly** for the best experience (logins need first-party cookies):
the "Embed this Space" / full-screen link, or `https://<owner>-<space>.hf.space`.

- Log in with any demo account listed on the login page.
- Ask the assistant (bottom-right button) things like *"Am I short in any course?"*.
- The database is reset with fresh synthetic data whenever the Space restarts.
